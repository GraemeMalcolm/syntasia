What persists

Only Project URL and Model name are saved in this browser and remain readable by same-origin scripts until cleared. If storage is blocked, continue in session-only mode.

Keys, advanced settings, scene edits, attachments, images, selections and generated media do not persist. Save changes invalidates affected work; Cancel discards unsaved settings. Clear settings removes saved values and active service settings.

Test connection must ask for confirmation before any billable model, research or synthesis request. Static preview controls do not run tests or save data.
